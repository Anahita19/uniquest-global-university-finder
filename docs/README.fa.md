# راهنمای فارسی UniQuest

UniQuest یک پلتفرم هوشمند برای جستجوی دانشگاه‌ها، بررسی شانس تطبیق، پیدا کردن بورسیه و برنامه‌ریزی هزینه‌های تحصیل بین‌المللی است.

## تغییر زبان

در نوار کناری از گزینه‌های `EN` و `FA` استفاده کنید. حالت فارسی چیدمان راست‌به‌چپ دارد و زبان منوی اصلی، جستجو، وضعیت حساب، منوی موبایل و بخش پایانی برنامه را تغییر می‌دهد. اطلاعات ذخیره‌شده پروفایل، علاقه‌مندی‌ها و مقایسه‌ها با تغییر زبان حذف نمی‌شوند.

## هشدار مهم درباره داده‌ها

نتایج پذیرش تضمینی نیستند. هر نتیجه باید با منبع رسمی دانشگاه یا بورسیه بررسی شود. وضعیت منابع با برچسب‌های `Verified`، `Estimated` و `Unconfirmed` نمایش داده می‌شود. هزینه‌ها، مهلت‌ها، رتبه‌بندی‌ها و شرایط ویزا قبل از اقدام باید در منبع رسمی دوباره بررسی شوند.
