# UniQuest delivery outcomes

## Responsive advisor workspace and bilingual foundations
- [ ] Deliver a premium, modern, trustworthy, responsive international education platform with clean typography, modern dashboard navigation, international university visual language, professional data visualization, English as the default language, and Persian language support with RTL layout.
- [ ] Allow users to switch English/Persian without losing saved data or application progress; keep forms, dashboards, university information, reports, emails, and navigation localizable.
- [ ] Support currency display and conversion for EUR, USD, GBP, CAD, AUD, and other major currencies with clearly labeled estimates.

## Student registration, profile, and document workflow
- [ ] Support registration with email or Google through real authentication, personal profiles, saved academic information, uploaded academic documents, favorites, application tracking, and personalized university report downloads.
- [ ] Implement a multi-step assessment form covering personal information, education level (High School, Bachelor's, Master's, PhD), degree, field, university, prior education country, GPA, grading scales (4, 5, 10, 20, 100), graduation year, optional ranking, work/research experience, publications, language certificates and section scores/dates/expiry, budgets, proof of funds, family support, fully funded need, application-fee willingness, preferred countries, degree, study language, study mode, intake, duration, university type, research/practical preference, and scholarship preference.
- [ ] Allow transcript PDF/JPG/PNG, graduation certificate, CV/resume, motivation letter, recommendation letter, and research proposal uploads; route transcript files through an AI/OCR integration, present extracted GPA/courses/grades/grading system/degree/major/graduation date/missing information for review and correction, and document grading conversion methods.

## Matching, scholarship, and evidence transparency
- [ ] Match real university programs using academic compatibility, degree/major fit, language and section requirements, finances, tuition, deadlines, country requirements, scholarships, and academic/research experience.
- [ ] Classify matches as Safe, Good Match, Ambitious, or Not Eligible, explain each result and missing requirement, never guarantee admission, and label indicative AI assessment when official admission statistics are unavailable.
- [ ] Show university name/logo, country/city, ranking source/year, degree level, program, field, instruction language, duration, annual/total tuition, application fee, deadline/intake, IELTS/TOEFL, minimum GPA, other requirements, scholarships, scholarship amount/eligibility, living expenses, official university/program/application links, and met/not-met indicators.
- [ ] Show source URL, last verified date, and Verified/Estimated/Unconfirmed state for recommendations, tuition, fees, deadlines, scholarships, and language requirements; show “Not confirmed – check official website” when needed; provide an update integration boundary.
- [ ] Create scholarship matching for fully funded, partial, government, university, merit, need-based, research, PhD, tuition waivers, monthly stipends, and accommodation support, including Erasmus Mundus, DAAD, OeAD, DSU, Stipendium Hungaricum, Chevening, Fulbright, Swedish Institute, and university-specific funding, with status Open/Upcoming/Closed, coverage, eligibility, documents, deadline, and official link.

## Deadlines, finances, comparison, and assistant
- [ ] Track application opening/deadline, scholarship/document/language deadlines, and interview dates with countdowns, saved deadlines, customizable email reminders, calendar support where available, and statuses Interested, Preparing documents, Ready to apply, Submitted, Under review, Interview, Accepted, Rejected, and Waitlisted.
- [ ] Calculate application fee, tuition, living, accommodation, food, transport, insurance, visa, proof of funds, and other expenses; show first-year, annual, total-program cost, financial gap, required proof of funds separately from actual costs, and potential scholarship savings.
- [ ] Compare up to five universities across tuition, fees, requirements, IELTS, GPA, scholarships, deadlines, living expenses, rankings, duration, and total estimated cost; highlight affordable and strongest academic matches.
- [ ] Provide an AI admission assistant that uses the saved student profile and current verified university information to answer questions about GPA, IELTS, application fees, scholarships, low tuition, no-IELTS options, deadlines, documents, and best country; do not fabricate answers or sources.

## Plans, admin, and production architecture
- [ ] Implement FREE, PRO, and PREMIUM subscription plans with the requested entitlements, subscription management, configurable payment gateway integration, free trial, billing dashboard, renewal/cancellation, secure payment handling, and no simulated payment success.
- [ ] Provide a personalized dashboard with profile completion, recommended universities, scholarship matches, upcoming deadlines, saved universities/scholarships, application progress, financial overview, AI recommendations, and downloadable PDF reports.
- [ ] Provide an admin dashboard to manage users, universities, programs, fees, scholarships, deadlines, countries, data sources, verification status, and AI matching settings, including manual correction and verification.
- [ ] Deliver a real full-stack architecture with durable database storage, real authentication, functional document upload, search/matching integration boundaries, schema/migrations, deployment instructions, API documentation, and data-source documentation. If external API credentials are unavailable, state the required keys and integration status instead of pretending the integration works.
